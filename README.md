# Solar-EV-Charging-Station
Smart Solar EV Charging Station using ESP32, IoT, and Firebase for real time monitoring and mobile app control. Features include solar powered EV charging, battery and voltage monitoring, safety alerts, and remote access through a smart application for sustainable and efficient energy management.
